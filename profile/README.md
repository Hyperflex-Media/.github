### 🔒 Core Projects & Initiatives

> **Note:** Repositories within this organization are currently private as we actively develop internal software, SaaS platforms, and custom tooling using AI-assisted (Claude Code) workflows.

- **Licensing API** — Built with Next.js, Tailwind CSS, and PostgreSQL to handle entitlement validation, key issuance, and backend licensing state.
- **Provisioning Platform** — Full-stack solution for automated access control and media share management (Plex, Jellyfin):
  - **Frontend:** Next.js & Tailwind CSS dashboard for administration and user management.
  - **Backend:** High-performance Hono API built on Node.js, tested with Vitest.
  - **Database & Auth:** Integrated with Supabase for data persistence and authentication services.
- **IaaS / SaaS Infrastructure & CI/CD** — Reverse proxy routing (NGINX, Apache2, Caddy), automated build pipelines, process orchestration, and infrastructure deployment management.

### 🛠 Architecture & Standards

- **Languages:** TypeScript & JavaScript
- **Frameworks & Styling:** Next.js, Hono, Tailwind CSS
- **Testing:** Vitest
- **Runtimes & Cloud Services:** Node.js, Supabase Platform
- **Data Tier:** PostgreSQL
- **Web Servers & Proxies:** NGINX, Apache2, Caddy
- **Process Management & Runtime:** PM2 process management on bare-metal / low-overhead hosts alongside Docker containerization where appropriate
- **Deployment & Infra:** Hybrid deployments managed via GitHub Actions and automated CI/CD pipelines
- **Development Workflow:** AI-assisted engineering with Claude Code
