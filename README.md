> **Note:** Repositories within this organization are currently private as we actively develop internal software, SaaS platforms, and custom tooling using AI-assisted (Claude Code) workflows.

- **Provisioning Platform** — Full-stack solution for automated access control and media share management (Plex, Jellyfin):

  - **Backend:** High-performance Hono API built on Node.js.
  - **Database & Auth:** Integrated with Supabase for data persistence and authentication services.
- **IaaS / SaaS Infrastructure & CI/CD** — Automated build pipelines, process orchestration, and infrastructure deployment management.
